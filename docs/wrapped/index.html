How to export your chat

Export the chat without media. It's faster and the cards only need the text.

WhatsApp on iPhone
  1. Open WhatsApp and go into the group chat.
  2. Tap the group name at the top of the screen.
  3. Scroll down and tap Export chat.
  4. Choose Without media.
  5. Pick Save to Files, then come back here, tap Choose your chat export and pick the .zip file.
WhatsApp on Android
  1. Open WhatsApp and go into the group chat.
  2. Tap the ⋮ menu (three dots, top right).
  3. Tap More, then Export chat.
  4. Choose Without media.
  5. Save it to your phone (for example to Drive or Files), then upload the .txt or .zip here.
Telegram (Desktop app)
  1. Telegram's phone apps can't export chats, so use Telegram Desktop on a computer.
  2. Open the group, click the ⋮ menu, then Export chat history.
  3. Untick photos, videos and files. Set Format to Machine-readable JSON.
  4. Click Export, then upload the result.json file from the export folder.

Your chat never leaves your device. How we know:

There's no server to send it to

This page is plain files on GitHub Pages. Your export is read, counted and drawn into cards by JavaScript running in this browser tab. Close the tab and it's gone.

The browser blocks it anyway

The page ships a Content-Security-Policy that only lets it talk to one outside address: the optional email signup below, which sends just your email. No analytics, no trackers, no third-party scripts, no web fonts.

It's open source

Every line is on GitHub: lanternlab2027/lab → docs/wrapped. The zip reader (JSZip) is copied into the folder, not loaded from a CDN.

Try it offline

Load this page, turn on airplane mode, then upload your chat. It still works, because nothing needs the internet.

Get notified about new card packs

Optional. We only send your email address. Nothing from your chat is ever included.

Questions

Is this made by WhatsApp or Telegram?

No. Group Chat Wrapped is an independent project that works with the export files those apps already let you make. It is not affiliated with or endorsed by WhatsApp, Meta or Telegram.

Does it work with one-on-one chats?

Yes, though a few cards (like the ghost) only appear in groups of three or more.

My file says "couldn't find any messages"

Make sure you uploaded the chat export itself: the .txt (or the .zip it came in) from WhatsApp, or result.json from Telegram Desktop with the JSON format selected. Exports from every phone language we know of are supported; if yours isn't, the open-source code is easy to fix.

Is it free?

Yes. The main deck is free. A bonus card pack is coming later.
