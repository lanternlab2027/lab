What Class A, B and C mean

HPD sorts housing code violations by hazard. Per HPD's "Clear Violations" guidance:

  • Class A non-hazardous. The owner has 90 days from service of the violation to correct it.
  • Class B hazardous. 30 days to correct.
  • Class C immediately hazardous. Most must be corrected within 24 hours; lead-based paint, window guards, mold, mice, roaches and rats within 21 days; self-closing doors within 14 days; heat and hot water immediately.

HPD also lists Class I entries: orders to repair and vacate orders, which are not ranked by hazard. A violation stays "open" until the owner certifies the correction and HPD clears it, so an open count can include problems already fixed but not yet cleared.
