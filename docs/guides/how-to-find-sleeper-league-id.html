How to find your Sleeper league ID

Fantasy tools ask for it all the time. It's in two places: the bottom of your league settings in the app, and the end of the league's web address.

Last checked: Nov 2026 against the official help pages listed under Sources.

Quick answer

App: open the league → League Settings → General League Settings → scroll down → copy League ID.
Web: open the league on sleeper.com; the ID is the long number at the end of the address, like sleeper.com/leagues/1180000000000000001 (example only).

Find your league ID in the Sleeper app

  1. Open your league in the Sleeper app.Tap the league from your home screen.
  2. Go to League Settings, then General League Settings.League settings are reached from inside the league.
  3. Scroll to the bottom and copy the League ID.Sleeper puts a copy option for the League ID at the bottom of General League Settings.

Find your league ID on sleeper.com

  1. Log in at sleeper.com and open your league.Use any web browser.
  2. Look at the end of the address bar.The league ID is the long number at the end of the URL, after /leagues/. Copy all of the digits.

Sleeper's help article describes the ID as an 18-digit number. Copy whatever digits are there, all of them; a shortened ID won't work.

Good to know

  • New season, new ID (probably). Sleeper's API docs show leagues with a previous_league_id field, which suggests a league that renews for a new season gets a new ID that points back to last year's. Sleeper doesn't spell this out, so if an old ID shows last season's data, grab the ID again from the current league.
  • You may not need the ID at all. Our Fantasy League Awards page also accepts your Sleeper username (it lists your leagues) or a pasted league link.

Troubleshooting

A tool says "league not found"

Check you copied the whole number, with no spaces or extra characters. Pasting the full league link is a safe fallback, if the tool accepts links. Make sure it's this season's league (see above).

I can't find the League ID in the app

Update the Sleeper app, then look at the very bottom of General League Settings. If it still isn't there, use the web method: open the league on sleeper.com and copy the number from the address bar.

Is the league ID the same as my user ID?

No. Your user ID belongs to your account; the league ID belongs to one league in one season. Tools that ask for a league ID need the league's number.

Privacy: what a league ID gives access to

Sleeper doesn't have an "export file" for leagues. Instead, its developer API is read-only and needs no login (Sleeper's docs: "No API Token is necessary"). That means anyone who has your league ID can look up:

  • the league name, settings and scoring;
  • members' usernames, display names and team names;
  • rosters, weekly matchups and scores, trades, waivers and other transactions.

It doesn't expose passwords, emails or payment details. Share the ID with your league and tools you trust; don't post it publicly if your league would rather keep its trash talk private.
