How to export your StoryGraph data

Download your StoryGraph library (books, ratings, reviews, moods and read dates) as a single .csv file.

Last checked: Nov 2026 against the official help pages listed under Sources.

Quick answer

On the StoryGraph website: top-right menu → Manage Account → export your data (the User Export page) → generate the export → download the .csv.

Export your StoryGraph library

  1. Sign in to The StoryGraph in a web browser.Go to app.thestorygraph.com on a computer or your phone's browser.
  2. Open the menu in the top-right corner and choose Manage Account.Or go straight to app.thestorygraph.com/manage-account.
  3. Open the export page.From Manage Account, follow the link to export your data. It goes to the User Export page, app.thestorygraph.com/user-export.
  4. Start the export.Use the button on that page to generate your StoryGraph library export.
  5. Download the .csv file when it's ready.Depending on the size of your library this can take a little while. Some guides say StoryGraph emails a download link; StoryGraph's help center doesn't say, so check both the page and your inbox.

What's official and what isn't: StoryGraph's help center doesn't have an export article. The route above comes from a StoryGraph team reply on its official roadmap board ("export your data on the User Export page, which can be accessed from the Manage Account one"), and its Getting Started article, which puts Manage Account in the top-right menu. StoryGraph doesn't document the exact button label, whether the file is emailed, or whether the phone app has the same page, so we don't state those as fact. If you don't see the option in the app, use a browser.

Troubleshooting

The ISBN column shows errors in Excel

This is a known issue on StoryGraph's roadmap (open since January 2024): Excel can mangle the ISBN column. The file itself is usually fine. Keep the original download and upload that to other tools instead of a re-saved copy.

My genres aren't in the export

The export includes your own tags, moods and pace, but not StoryGraph's genre tags. Users have asked for genres on StoryGraph's roadmap; it isn't there yet.

I want to move my Goodreads books into StoryGraph instead

That's the import, not the export. StoryGraph's Getting Started article says to go to Manage Account in the top-right menu and use the Goodreads import. You'll need your Goodreads export file first.

Page counts are missing

StoryGraph's library export doesn't include page counts or community ratings, only your own data. If you need those, a Goodreads export has them.

Privacy: what's in a StoryGraph export file

The CSV is one row per book, with columns including:

  • title, authors, contributors, ISBN and format;
  • read status (read, currently reading, to-read, did not finish), dates added and read, and read count;
  • your star rating, review, moods, pace and character answers;
  • your content warnings, tags and whether you own the book.

Your reviews and tags are in the file even if they're private on StoryGraph, so check before you share it.
