How to export your Libby timeline

Get every library ebook and audiobook you've borrowed out of Libby as one spreadsheet file, straight from the app.

Last checked: Nov 2026 against the official help pages listed under Sources.

Quick answer

In Libby: Shelf → Timeline → Actions → Export Timeline → Spreadsheet. You get a .csv file of every borrow, return and hold.

Export your Libby timeline

  1. Open Libby and tap Shelf.It's in the navigation bar at the bottom of the app (or the bottom of libbyapp.com in a browser).
  2. Tap Timeline.It's at the top of the Shelf screen. Your timeline lists the titles you've borrowed, returned and placed on hold.
  3. Clear any filters you don't want.Libby's help says any active filters are applied when you export. For a whole year in books, export everything; you can pick the year later.
  4. Tap Actions, then Export Timeline.Libby asks which format you want.
  5. Choose Spreadsheet.Libby saves the timeline to your device as a file you can open in a spreadsheet app. Tools we checked find it named libbytimeline-activities.csv. Table makes a shareable web page instead of a file.

Table or Spreadsheet: which to pick

  • Spreadsheet saves a file to your device so you can review or edit it. Pick this one for other tools, including Reading Wrapped.
  • Table shows your timeline on a web page you can bookmark or share with friends. Anyone with that link can see the page, so share it with care.

About our check: Libby's help article (last updated September 2026) lists exactly two formats, Table and Spreadsheet. Older open-source tools describe a Data (JSON) option and links ending in libbytimeline-….json; we couldn't find that option in Libby's current help, so it may have been removed or renamed. Libby doesn't publish the spreadsheet's columns. The ones below come from open-source tools that read real exports, not from OverDrive.

What's in the spreadsheet

One row per event, newest first. Open-source tools that read real exports find these columns: Cover, Title, Author, Publisher, ISBN, Timestamp, Activity, Details, Library. Activity is the event, such as Borrowed, Returned or Placed on hold; for a loan, Details holds the loan length (for example "21 days").

A book you borrowed and returned shows up on two rows (more if you held it or borrowed it again). There's no rating, page count or "finished" flag: Libby records loans, not reading.

Troubleshooting

My timeline is missing older loans

First check that no filter is on (see the next answer). Beyond that, Libby's help pages we checked don't say how far back the timeline goes or how it moves to a new phone, so we can't promise older loans are recoverable. If you've switched devices, make sure you're using the same Libby setup and library cards, and ask your library if something is still missing.

The export only has some of my books

A filter was probably on. Go back to Timeline, clear the filters, and export again: Libby applies active filters to the export.

I tapped Table and got a link, not a file

That's the shareable web page. Go back to Actions → Export Timeline and choose Spreadsheet to save a file instead.

Can I import this into Goodreads or StoryGraph?

Some library help pages say the spreadsheet can be imported into Goodreads, and community tools convert it for StoryGraph. The columns don't match Goodreads' own export, so expect to tidy it up. Reading Wrapped reads the Libby file directly, no conversion needed.

Privacy: what's in a Libby timeline export

The file is your library borrowing history. It contains:

  • the title, author, publisher and ISBN of every book, audiobook and magazine you borrowed or held;
  • the date and time of each borrow, return and hold;
  • the name of the library each loan came from, which can hint at where you live.

Libraries treat borrowing records as private for good reason. Keep the file to yourself, and delete copies from email or cloud storage when you're done. A Table link shows the same history to anyone who opens it.

Turn your Libby history into shareable cards, on your device

Reading Wrapped reads libbytimeline-activities.csv and makes year-in-books cards: books borrowed and returned, your reading rhythm, favorite author and a Library love card with your loans, favorite library and ebook vs audiobook split. Free, and your history never leaves your browser.
