    Questions

    Do I need to sign up or collect emails?

    No. Type first names and you get one private link per person. Send each one by text, WhatsApp, email or carrier pigeon. Nobody makes an account.

    Can the organizer peek?

    This page never shows the matches, and each match is scrambled inside its link, so glancing at a link or a chat preview gives nothing away. But a link is a key: whoever opens it sees what it says. So we're honest about it: if you're organizing, open only your own link. Tick "I'm in the draw too" and we'll point you to yours.

    Is anything stored on a server?

    No. The draw runs in your browser using its secure random number generator. Each match lives only in the part of the link after the #, which browsers never send to any server. There's no database, no tracking and no ads.

    Can couples be kept from drawing each other?

    Yes. Add them as a pair. If your pairs make a draw impossible (say, 3 people where 2 are a couple), we'll tell you instead of guessing.

    What if someone loses their link?

    Resend it from this page if it's still open, or from the list you copied. If the list is gone, start over and send everyone new links, and ask them to ignore the old ones.

    Can people share a wishlist?

    Yes. On their reveal page, anyone can write a wishlist and get a link to drop in the group chat. Their Santa sees it, and nobody learns who has whom.
