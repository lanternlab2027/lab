      How the no-account pool works

      1. The host makes a pool link: show, pool name, scoring and an optional tiebreaker. All of it is packed into the link. Post it in the group chat.
      2. Everyone picks from that link on their phone and taps "Get my picks link". That link holds their name and every pick. They send it back to the host.
      3. The host pastes the picks links into the leaderboard. During the show we post winners to this site as they are announced; refresh to see the standings move. At the end, share the award pictures.

      Nothing is stored on a server. No accounts, no sign-ups, and we never see your pool or anyone's picks. Everything lives in the links, in the part after the #, which browsers don't send to any website. The page only downloads the show and results files from this site.

      Honest-play checks. Each picks link carries a checksum, so a hand-edited link shows up as "edited link". Each link also records when it was made, and a ballot made after the lock time shows as "late". They are honest-play checks, not security.

      No money, no entry fees, no prizes: this is a free pool for bragging rights.

      Questions

      Which shows can I run a pool for?

      The 2027 film and TV awards on Jan 10, the recording academy's music awards on Feb 7, and the film academy awards on Mar 14, plus a demo show to try it out.

      When can people fill in their ballots?

      As soon as the nominations are announced and we add the nominees here, usually the same day. You can make the pool link before that; it shows the ballot as soon as the nominees are in.

      How do I print an awards ballot?

      Pick the show under "Printable ballot" and tap "Print ballot". Only the ballot prints. Choose "Save as PDF" in the print dialog for a PDF. Before nominations it prints with blank lines to write the nominees in.

      How does the weighted scoring work?

      Each category has a weight from 1 to 3 in our show file: the top awards count 3, acting and other headline awards 2, everything else 1. The ballot shows each category's points when the pool uses weighted scoring.

      Where do the winners come from?

      We post winners to a results file on this site during the ceremony, as each award is announced, and check them against the official results. Your browser downloads that file and scores every ballot on your own device. Hit "Refresh results" to update.

      What if someone changes their picks after the show starts?

      A new picks link records when it was made, so the leaderboard marks it late. If someone edits a link by hand, the checksum no longer matches and it is marked "edited link". The host decides what to do about either.

      Is this official?

      No. It is an independent, free fan tool, not affiliated with, endorsed by or connected to any awards organization. Show, film, artist and program names are used only to identify the nominees.
